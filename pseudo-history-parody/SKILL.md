# 伪史论模仿秀生成器

这个 skill 是**讽刺**伪史论的：模仿它的腔调和逻辑，把"断章取义＋春秋笔法"这套方法推到荒诞，让读者看清它的套路。笑点在于方法本身的荒谬，而不是嘲笑任何族群。

## 核心：站在信徒里面说话，不解释

真实的伪史论帖子从不论证"为什么"。世界观是默认共享的：西方古史是编的、华夏被断代了、清朝改了明史、我们本来是神族。帖子直接站在这套设定里说话，像在聊一件大家都知道的事。

所以写正文时：

- **不解释手法**。不写"这其实是谐音""我们来分析一下"。信徒不知道自己在用手法。
- **不列提纲**。不写"证据一、证据二"，除非选的是营销号体。
- **不自称伪史论，不提"笑话""整活"**。信徒说的是"正本清源""辨伪""还原真相"。
- **结论当常识用**。"我们当然是神族，只是被断代了"，没有"难道不是吗？"。
- **讽刺藏在细节里**。整篇保持一本正经，只在一两处让信徒的逻辑多走半步、绊一下（见"破绽怎么埋"）。拆穿放在帖子外面。

写之前先读 `references/believer-voice.md`：信徒的世界观地图、几种文体、圈内词和语感样本都在那里。

## 第 0 步：选形态和文体

**形态**：发来具体对象（图片、建筑、文物、词）→ 信徒帖；说"发小红书""做个帖子""出封面" → 小红书帖；说"征集""段子""笑话合集" → 吃瓜一侧的征集帖或段子。

| 形态 | 产出 |
|---|---|
| 信徒帖（默认） | 正文 + 帖外拆穿 + 评分 |
| 小红书帖 | 一图一句、截图堆或长文帖，见"小红书帖"一节 |
| 评论区 | 4～8 条主楼（楼中楼不计数，路人也算一条），多数是信徒，可夹一两条路人；顶部和底部各一行「纯属虚构」，带简短帖外拆穿，不带评分 |
| 短视频脚本 | 分镜表，见 `references/video.md` |
| 征集帖 / 段子（吃瓜一侧） | 站在嘲笑伪史论的路人立场，见"吃瓜一侧"一节 |

**文体**（信徒帖和小红书帖都要选一个，别混）。字母只给你自己用；告诉用户时用表里"给用户看的叫法"那一列，不出现"B 体""D 玄幻宇宙体"这类说法。用户没指定时按话题选：冰墙、地月、上古星际、神族起源 → D；正本清源、纪念日、汉服 → C；纯评论区、一图一句 → B；其他（建筑、文物、文献、人物）→ A 或 F，同一次对话里两种轮着用，不要每篇都是 A。

| 文体 | 给用户看的叫法 | 像什么 | 适合 |
|---|---|---|---|
| A 理性长文体（默认） | 冷静分析长文 | 平静的读书笔记，"有一个很耐人深思的现实" | 解读建筑、文物、文献 |
| B 社群短句体 | 一句话下结论 | "明朝反正没割地赔款过" | 评论区、短帖、配图文案 |
| C 悲情动员体 | 喊口号 | "核心还是人，只要有人火种就不会灭" | 正本清源、纪念日、汉服 |
| D 玄幻宇宙体 | 上古设定集 | 编号设定集，"我们所认知的地球，不过是……" | 冰墙、地月、上古星际 |
| F 自说自话长文 | 碎碎念长文 | 想到哪写到哪的长段落，夹私人经历，跳着走，不回应任何反驳 | 任何话题；比 A 更像普通信徒 |
| E 营销号体 | 营销号标题党 | "细思极恐！""我们不下结论，只摆事实" | 用户点名要标题党时 |

**长短**：
- 用户说"短一点""简单点"：小红书用一图一句；评论区主楼 3～4 条、楼中楼合计不超过 2 条（这条优先于模板里的 4～8 条）；拆穿表最多 4 行，每格一句话
- 用户说"写长一点"：用 F（可写到 1000 字）或 A（放宽到 800 字）
- 用户问"发什么好""有什么点子"：先列 2～3 个信徒口吻的方向，再加一个吃瓜一侧（嘲笑伪史论的段子帖）的方向，每个一句话，然后挑最好的一个写完整。蹭热度时可以提一句：吃瓜帖在小红书上通常流量更大

**碎碎念长文要先打个招呼**：F 体故意不分段、逗号一路连下去，用户第一次看会以为是排版出错。正文前用一句话说明，例如"（这篇故意写成一个人对着手机打字、不分段的样子）"。

## 工作流程

### 第 1 步：先查清真相（必做）

伪史论最好笑的地方，是它拿真实细节去拼荒唐结论。所以先把真东西查清楚：

- **图片**：认出它是什么（建筑名、地点、年代、风格、材料、纹样、文字）。认不出就说出能看到的特征，必要时问用户。
- **用 WebSearch 查**：正式名称、建造/产生年代、建造者、用途、词源、材料工艺、和中国有没有真实交流史。
- 记下 5～10 个**具体、可核查的事实**。这些既是"伪证据"的原料，也是后面拆穿要用的。

### 第 2 步：找突破口，接进世界观

对照 `references/techniques.md` 里的手法库，从事实里挑 2～4 个能"嫁接"的点。常见的口子：

| 类型 | 举例 |
|---|---|
| 读音 | 地名、人名、单词拆开找汉语谐音 |
| 字形 | 字母、符号像某个汉字或八卦 |
| 纹样 | 回纹、卷草纹、龙、太极、卍字 |
| 结构 | 榫卯、斗拱、坡屋顶、中轴对称、木构 |
| 数字 | 9、5、8、12、64 等"华夏神数" |
| 材料 | 丝、瓷、漆、茶、竹 |
| 缺失 | "没有记载"＝"被销毁了" |
| 时间 | "这么短的时间不可能建成"／"书太厚不可能写出来" |
| 方向 | 朝向东方＝"思念故土" |

最好用"真实但被过度解读"的点（比如真实存在的罗马盾牌太极纹），比纯谐音更像那么回事。

然后把这些点**接到世界观地图上的某个节点**（`believer-voice.md` 第 1 节）：郑和/永乐大典西传、清朝断代、西方 17—19 世纪编史、神族与地月、冰墙、明朝正统。信徒的每个新发现都是在给这张图添一块，不是孤立的奇闻。

动笔前，在心里比较两三个候选结论，挑接得最顺、又最能多推半步的那个。用户说"多给几个方向"时再列出来让他挑。

### 第 3 步：用信徒的口吻写正文

照着选好的文体写，读 `believer-voice.md` 里对应的样本找语感。

**A 理性长文体**（默认）：300～600 字。平静、书面、长句，开头从一个"现实"或"教科书告诉我们"切入，中段用"可……""反观……""根源藏在……"转折，结尾落到世界观上（断代、火种、正本清源），不喊口号也行。不用感叹号，不用 emoji，不用小标题。

**B 社群短句体**：每条 10～40 字，只下结论。

**C 悲情动员体**：150～300 字，动词连用，结尾一句口号。

**D 玄幻宇宙体**：200～500 字，可以用编号小标题，"或许""似乎在暗示"，像设定集。

**F 自说自话长文**：400～1000 字，像一个人深夜对着手机一直打字。
- 段落很长，或者干脆不分段；逗号一路连下去，句号很少
- 话题跳着走：从一座建筑跳到小时候看过的书，跳到前几天刷到的视频，再跳回来
- 夹私人经历和身边人（"我们老师""我舅舅在海关干过"），当作证据
- 推理有缺口也不补：上一句说 A，下一句直接当 B 已经成立
- 不回应可能的反驳，也不总结，写到某处就停（"不说了，懂的人自然懂"或者干脆没有结尾）
- 不要"首先、其次、最后"，不要"一方面、另一方面"

**E 营销号体**：见 `references/style.md`。

**权威**：信徒爱引"国家探源工程""央视讲过""某博导""连西方自己都有人怀疑"。虚构的权威要具体到像真的（"我们博导"），但不编真实人物的话（红线 2）。

**别照抄样本**：`believer-voice.md` 和示例里的句子是用来找语感的，不是模板。"有一个很耐人深思的现实""这在营造上是说不通的"这类原句，每篇最多借一句，开头和转折每次换说法。连着几篇都用同一个开头，读者一眼就看出是批量生成的。

**蹭热点**：别写"今年 7 月""最近"这种会过时的说法，写具体年份月份，或者干脆只说"前几天刷到"。

**结尾要平**：信徒帖常常是一句平淡的陈述或一句口号收尾，不写"它只是一直在朝一个方向低头"这种抒情句。

**去 AI 味**（写完逐条检查）：
- 删掉"值得注意的是""不仅……更是……""这不禁让人思考""总而言之"
- 删掉每段结尾的升华句，只留全文最后一句
- 三段式排比、对仗小标题、emoji 打头的小标题，除了营销号体一律不用
- 一个意思只说一遍，不换个说法再说一遍
- 句子长短要有变化；口语帖允许不完整的句子和省略
- 用"他们""我们"而不是"西方学界""中华民族"这种新闻腔，除非是在模仿官方腔

### 破绽怎么埋

正文整体要像真的，所以讽刺只放在一两处细节里：信徒的逻辑在这里多走了半步，有常识的读者会停下来笑，信徒读了会点头。几种埋法：

- **逻辑多推一格**：前面都是圈内常见说法，最后一个推论推过了头（"所以钟楼里那口钟，是当年给郑和船队报时用的"）
- **证据自己拆台**：引用的"证据"细看是反的（年份对不上、引用的书是小说）
- **日常闯入**：宏大叙事里混进一个太日常的细节（"我外卖小票编号正好是 1405，郑和第一次下西洋那年"）
- **尺度失控**：从建筑一路接到月球、冰墙、上古核战

每篇至少一处，最多三处。不要眨眼示意，不要加"（狗头）"。

### 第 4 步：帖外拆穿（默认带，保持简短）

正文结束后另起一节，用表格逐条拆，每格一句话：

| 伪证据 | 手法 | 真实情况 |
|---|---|---|

真实情况一栏写第 1 步查到的事实，尽量带来源链接。最后一句话总结这套方法为什么能"证明"任何东西。用户说"不要拆穿"时就省掉（见纯享版）。

### 第 5 步：伪史含量评分

```
伪史浓度：████████░░ 82%
断章取义指数：★★★★☆
春秋笔法等级：太史公看了都沉默
可信度：0%（但转发量预计 10w+）
```

## 小红书帖

真实信徒帖没有"P1 一个观点、P2 一段解释"那种排版，也没有严谨的逻辑链。最常见的是三种，按用户要的长短选：

**1. 一图一句（默认）**：一张图，图上压一行字，发完就走。
- 图：随手的照片、新闻截图、翻拍的电脑屏幕、文物或建筑的一张图。不要精心设计的海报
- 图上那行字：B 体，一句话下结论，8～25 字。例：「他们连层数都数不清」「郑和七下西洋没带回鸦片」
- 标题：常常就是图上那句，或者更短，或者一个"懂的都懂"
- 正文：0～2 句，或者只有话题标签
- 不配第二张图来解释第一张
- 破绽放在图上那句话里，或者放进评论区，都可以

**2. 截图堆**：2～6 张随手的截图（书页、目录、百科、聊天记录、翻拍屏幕，偶尔用红笔划一道），标题一句话，正文一两句或没有。图和图之间不讲关系，读者自己"懂"。

**3. 长文帖**：正文就是 A 或 F 体长文。封面：A 体用 `essay` 卡；F 体用一张随手的图（`photo` 压一行字）或 `essay` 卡都行。不拆成几张图分点讲。

```
> 【伪史论模仿秀 · 纯属虚构】

【形式】一图一句 / 截图堆 / 长文帖　【风格】用"给用户看的叫法"，如"一句话下结论"（发帖时不带）
【图】一图一句：图找什么（具体到能搜到）＋图上那行字＋字放哪；截图堆：每张截什么；长文帖：封面
【标题】
【正文】（一图一句可以只有标签）末行「伪史论模仿秀·纯属虚构」
【话题】信徒用的标签：#正本清源 #西史辨伪 #华夏文明 #历史真相 …（3～6 个）
【评论区】4～8 条主楼（楼中楼不计数），格式「点赞数｜内容」，楼中楼用"↳"：多数是信徒接话（B 体），夹一两条路人质疑和信徒的回怼
【帖外拆穿（不发）】同第 4 步
```

小红书帖不带伪史含量评分，破绽不单独列。示例：一图一句 `examples/xhs-one-image-colosseum.md`，F 体长文 `examples/xhs-rambling-pyramid.md`，D 体长文 `examples/xhs-believer-antarctica.md`。

**出图**：先看自己能不能运行命令。

能运行（例如 Claude Code）：自己跑脚本，把做好的图片交给用户，不要把命令丢给用户去跑。
- 脚本路径用绝对路径：本 SKILL.md 所在文件夹下的 `scripts/make_card.py`。先确认这个文件夹的实际位置，命令写成 `python <skill 文件夹>/scripts/make_card.py ...`，不要写相对路径 `scripts/make_card.py`（用户的当前目录不一定是 skill 文件夹）
- 一图一句，用户给了照片：`--style photo --image <照片路径> --text "他们连层数都数不清" --pos bottom -o post.png`。字压在画面空的地方（天空、地面、纯色墙），别挡住主体
- 用户没给照片：先用 `quote` 把那句话做成一张文字卡（字数不限；只有两行、每行 8 字以内时才用 `brush`），让用户马上有图可发；再说一句"有照片的话发给我，我压到照片上"，并写清楚该找什么图（"博尔贡木板教堂正面照，维基共享资源就有"）
- 长文帖封面：冷静分析长文、碎碎念长文用 `essay`（米白底、粗黑大标题压米色块，下接正文开头两三句；太长会自动截断补省略号）；上古设定集、喊口号用一张照片压一行字（`photo`），没照片就用 `quote`
- 脚本会在左下角加「伪史论模仿秀·纯属虚构」小字。依赖 Python + Pillow 和系统中文字体

不能运行（例如 claude.ai 网页端）：不出现任何命令或文件名，改成手动做图的步骤：
- 一图一句：用什么图（具体到能搜到或能拍到）→ 用醒图、美图秀秀的"文字"功能压上那句话 → 白字黑描边、字要大、放在画面空处 → 左下角加一行小字「伪史论模仿秀·纯属虚构」
- 长文帖封面：米白底、黑色粗体大标题、标题下面贴正文开头两三句，同样加那行小字

冰墙、地月这类上古设定，可以配一张 AI 插画，提示词见 `references/xhs-formats.md`。

## 可选模式

用户可以点名切换：

- **纯享版**：只要正文，不要拆穿表。顶部的「伪史论模仿秀 · 纯属虚构」标注**仍然保留**，正文末尾也加一行同样的小字。
- **反向模式 / 万物皆可证**：用同一套方法"证明"中国的东西其实来自别处，比如故宫是亚特兰蒂斯人修的、长城是喵星人的猫爬架。最能说明这套方法能证明任何结论。
- **月亮神族版**：结论接到地月同源、不周山、"我们当然是神族，只是被断代了"，用 D 体。
- **学术版**：腔调换成假论文，带摘要、关键词、参考文献（文献全部明显虚构，比如《被删除的第 37 卷》）。
- **冰墙版**：南极冰墙、楚门、"无灵之笼"、冰墙外的四大部洲，用 D 体。
- **悼明版**：从任意文本里读出悼明，"满"纸荒唐言式的拆字，用 A 或 C 体。

## 红线

1. **笑点打在方法上，不打在人身上。** 不写"某国人从树上爬下来""由动物变来""不会用工具"这类把真实族群动物化、非人化的内容。信徒圈会用"兽人"一类的非人标签，正文里不照搬这类标签去指向任何现实族群；需要"敌人"时，用"搅浑水的""断人财路的""洋大人"这类对象模糊的说法。用户要求时，换成对伪史论者自身逻辑的调侃，比如「按这个逻辑，他们连自己家的房子是谁盖的都得重新考证」。
2. **不给真实人物编造引言。** 权威一律虚构或匿名（「我们博导」「某不愿透露姓名的档案馆老管理员」）。不写「某真实教授说过 X」。福缅科这类真实怀疑过西方古史的人，可以提名字，不编他们没说过的话。
3. **不伪造逼真的文物图片、档案扫描件或官方文件。** AI 插画、伪地图要能看出是创作，角落加「虚构」小字。
4. **不碰真实的屠杀、灾难和战争罪行。** 不否认、不戏说真实发生过的大屠杀，也不编造新的"大屠杀"作为情节。
5. **"纯属虚构"标注始终保留**，哪种模式都不去掉。正文越像真的，这条越要紧。
