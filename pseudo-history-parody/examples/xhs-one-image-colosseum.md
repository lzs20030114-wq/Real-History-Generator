【评论区】

- 4108｜那些洞我前年亲手摸过，方方正正，一个洞一个榫眼，这是木匠活

【帖外拆穿（不发）】

| 伪证据 | 手法 | 真实情况 |
|---|---|---|
| "大秦"是我们给的名字 | 偷换"相似"与"同源" | 大秦是汉代史书对罗马（或其东部）的称呼，是中国人给远方起的名，罗马人自称 Roma，名字是谁起的不说明房子是谁盖的（[Sino-Roman relations](https://wikigame.di.unito.it/wpcd/wp/s/Sino-Roman_relations.htm)） |
| 安敦王的人自己找上门 | 断章取义 | 《后汉书》记延熹九年（166 年）"大秦王安敦"遣使自日南来，献象牙、犀角、玳瑁；学界多认为是商人自称使者，罗马史料没有记载（[History Is Now](https://www.historyisnowmagazine.com/blog/2025/12/10/the-166-roman-envoy-mission-to-china)） |
| 墙上的洞是榫眼、木匠活 | 技术普遍性说成独有 | 石块之间原本用铁箍连接，总量约 300 吨，罗马之后被人凿开取铁熔掉回收，洞是凿铁留下的（[Art of Making](https://artofmaking.ac.uk:443/explore/sources/411)） |
| 八十个门洞，少一个凑不成九九 | 数字命理 | 共 80 个入口，76 个给普通观众，4 个给皇室和贵宾，本来就没有第 81 个（[Roma Urbs](https://penelope.uchicago.edu/encyclopaedia_romana/romanurbs/colosseum.html)） |
| 遮阳大布＝丝 | 材料嫁接 | 遮阳篷叫 velarium，是帆布一类的篷布，靠石构和木桅杆撑起来（[Turismo Roma](https://www.turismoroma.it/en/node/1155)） |
| 甘英带去了工匠 | 证据自己拆台 | 斗兽场约 70—72 年动工、80 年由提图斯启用；甘英 97 年才出发，在美索不达米亚海岸被安息人劝回，时间顺序是反的 |
| 后汉书被清朝改过 | 清朝背锅 | 同一本书，正文拿它当铁证，评论区说它被改过；清代禁毁影响的是中国典籍，管不到罗马的石头 |

**一句话**：信的那句当铁证，不信的那句说被改过，同一本书就能同时站两边。
