# 😱细思极恐！挪威深山里这座"教堂"，屋檐上竟盘着四条中国龙

我们不下结论，只摆事实。

挪威西部，莱达尔深山，有一座被称为"博尔贡木板教堂"的建筑。官方说它建于公元 1200 年前后，是**维京人的后代**修建的。

但问题恰恰就出在这里。

**证据一：飞檐叠瓦，层层出挑**
请看它的屋顶：一层压一层，层层向外挑出，檐角上翘。这种重檐结构，不就是我们再熟悉不过的**重檐歇山顶**吗？一个刚刚放下战斧的海盗民族，从哪里学会的这种营造法式？

**证据二：屋脊盘龙，镇守四方**
更令人后背发凉的是，四个屋脊尽头，各探出一颗**龙头**。东西南北，四龙镇守，这正是华夏"四方神兽"的格局！西方的龙是长翅膀、喷火、被骑士屠杀的恶兽，谁会把恶兽供在教堂顶上？除非，**这根本不是他们的龙**。

**证据三：通体乌黑，大漆防腐**
整座建筑通体乌黑发亮。当地人说这是"松焦油"。但懂行的人一眼就能看出，这种工艺与我国**髹漆**之术何其相似。漆，是华夏独有的宝藏，《尚书·禹贡》早有记载。你品，你细品。

**证据四：层数之谜**
有趣的是，西方资料对屋顶层数各执一词：有说六层，有说七层。**为什么连层数都对不上？**因为真相不能说！六加七等于十三，去掉顶上一层塔楼，恰好是**十二**——正合十二地支。

**证据五：坐西朝东，遥望故土**
最后，也是最让人动容的一点：这座建筑的主祭坛，**朝向正东**。东方，有什么？

据一位在奥斯陆档案馆地下室工作了三十年、不愿透露姓名的老管理员私下坦言："这些房子是谁盖的，我们心里都清楚。"

被篡改的历史，终将由我们亲手夺回。转发出去，让更多人看到。

## 🔍 拆穿时间

| 伪证据 | 手法 | 真实情况 |
|---|---|---|
| 重檐＝歇山顶 | 普遍形状说成独有 | 多层叠檐是为了在多雨多雪的地区排水、保护木结构，北欧木构有自己的发展序列，和中国的斗拱、举折体系完全不同 |
| 四龙镇四方 | 偷换"相似"与"同源" | 龙头造型和维京船首雕刻一脉相承，是北欧本土母题，一般解释为辟邪；而且现存龙头大多是 1738 年的复制品 |
| 黑色＝大漆 | 偷换概念 | 外墙涂的是松焦油（pine tar），北欧造船和木构常用的防腐材料，和漆树汁做的大漆是两种东西 |
| 6＋7−1＝12 | 数字命理 | 层数说法不一，只是因为大家对"一层"的划分不同。为了凑数又加又减，是典型的"先开枪再画靶" |
| 朝东＝思念故土 | 方向与天象 | 中世纪基督教堂普遍东向，祭坛朝向日出与耶路撒冷方向，是有文献依据的礼仪传统 |
| 匿名老管理员 | 假权威 | 无法核查的引言等于没有引言 |

**一句话总结**：只要允许"像"就等于"是"，允许数字随便加减，允许没有证据就算被销毁，这套方法可以证明任何建筑是任何人盖的。
